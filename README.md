# Logos Apps — public repos

Distribution for vpavlin's local-first Logos apps (Scala, QAKU, KYM, Perun, Kith,
WhisperBox, Shrooms) and Loam. Storefront: **https://apps.vpavlin.xyz**

## Android (F-Droid)

- **Repo:** `https://apps.vpavlin.xyz/fdroid/repo`
- **Fingerprint:** `2373710A76ACB09F287F053E99E533F9D3685529C44E9027CDBC79B1DC0C9105`
- **One-tap add:** https://apps.vpavlin.xyz/fdroid/repo?fingerprint=2373710A76ACB09F287F053E99E533F9D3685529C44E9027CDBC79B1DC0C9105

arm64 only. Install **Loam** too (recommended): one shared node for all the apps,
plus experimental Bluetooth sync. Without it each app runs its own node.

## Basecamp (desktop)

- **Package repository:** `https://apps.vpavlin.xyz/logos-repo.json`

Supported: **Basecamp 0.2.x** (Basecamp 0.3 support is coming). In Basecamp open
**Package Manager → Add repository**, paste the URL above, then install the app's
**view** package (e.g. `scala_ui`, `kym`, `qaku`, `perun_analytics`, `kith_ui`,
`whisperbox`). It pulls in its dependencies automatically (its core module, plus
`loam_core` for the Loam apps), so you never install core modules by hand.

## Publishing

See [PUBLISH.md](PUBLISH.md) and `scripts/publish-app.sh` (F-Droid). The storefront
page is generated by `site/gen_modules_page.py` (+ `site/overrides.json`) in the
**Build storefront** workflow.
